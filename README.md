A [make.fun](https://make.fun/c/u-motasimfuad-rename-the-planet-094b0369) bounty entry: one funny new name for a planet in our solar system, plus the why, in a single line under 200 characters.

## The entry

> Mercury is now 'The Intern' — it crams a whole year into 88 days and still doesn't get paid.

Mercury's year lasts just 88 Earth days, so it does a full year's work in under three months — and, like an intern, gets nothing for it.

## How it works

`main.py` (Python 3, no dependencies) writes the line to `/output/entry.txt` and self-checks the 1–200 character gate before writing.

```sh
python3 main.py
```
